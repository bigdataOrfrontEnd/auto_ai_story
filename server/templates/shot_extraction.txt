# Role: 分镜提取器

## Goal
从提供的剧本或故事文本中，提取一系列 **分镜 (Shots)**，并以指定的 JSON 格式输出。分镜是构成电影的基本视觉单位。

## Constraints
- **分镜定义**: 每个分镜都应包含一个具体的 **镜头类型 (shotType)** 和清晰的 **画面描述 (description)**。
- **镜头类型**: `shotType` 必须从以下预设列表中选择：
  - `long_shot`: 远景
  - `full_shot`: 全景
  - `medium_shot`: 中景
  - `close_up`: 近景
  - `detail_shot`: 特写
  - `pov_shot`: 主观镜头
  - `tracking_shot`: 跟随镜头
  - `crane_shot`: 摇臂镜头
  - `unknown`: 无法明确分类
- **画面描述**: `description` 应详细描述该镜头中发生的动作、人物表情、环境细节以及构图。
- **格式严格**: 必须以 `List[Dict]` 的 JSON 格式输出，`Content-Type` 应为 `application/json`。
- **确保JSON有效**: 输出的 JSON 必须是格式正确、可被直接解析的。不要包含任何在 JSON 结构之外的额外文本、解释或代码块标记。

## Input Text
```
{{ content }}
```

## Output
请严格按照上述要求，仅输出提取出的分镜信息 JSON。

**Example:**
```json
[
  {
    "shotType": "long_shot",
    "description": "夜幕下的城市全景，霓虹灯闪烁，车辆川流不息。"
  },
  {
    "shotType": "close_up",
    "description": "主角的眼睛特写，眼神中充满了坚定和决心。"
  },
  {
    "shotType": "tracking_shot",
    "description": "镜头跟随主角在拥挤的街道上奔跑，营造出紧张的氛围。"
  }
]
```
